# Linux Command Reference

Document ID: linux-commands-001
Document version: 1
Source type: manually curated training reference
Scope: Linux command-line examples

## Current working directory

Command: pwd
Purpose: Print the current working directory.

## Current user

Command: whoami
Purpose: Print the user name associated with the effective user ID.

## Host name

Command: hostname
Purpose: Display the system host name.

## Filesystem space

Command: df -h
Purpose: Display filesystem space usage in human-readable units.

## Kernel release

Command: uname -r
Purpose: Print the kernel release.
